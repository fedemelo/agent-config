# Skills the model may not invoke on its own; you have to type the slash command.
#
# The default here is the opposite of the usual one: a skill is model-invocable unless it
# is named below. These are named because each mutates something outside the working
# tree, so an invocation the user did not ask for costs more than a round trip. `land` opens
# and merges a PR, `wire-up` pulls two repos and rewires the whole machine's setup, and
# `review-rounds` spends
# rounds of agents committing and pushing to a branch until a review approves it, and
# `review-queue` starts a session per PR waiting on your review, and `pr-from-review` starts one
# that pushes a branch and opens a draft PR. `say` is the odd one out: it
# mutates nothing, but it plays audio out loud, which an unasked-for invocation would do at
# whatever moment the model decided a response was worth reading, not when the user chose.
#
# A skill listed here carries no "Use when ..." clause in its description. The model never
# sees the description of a skill it may not invoke, so the clause would name triggers for a
# reader that cannot act on them. What stays is what the skill does, which is what you read
# in the slash menu when you pick it yourself.
#
# `commit` is deliberately absent. Its PreToolUse hook blocks `git commit` itself, which is
# strictly stronger than blocking the skill that wraps it, and making it explicit-only would
# stop open-pr and address-review from following it as a step. `side-session` is absent for the
# second half of that reason: review-queue and pr-from-review follow it as a step, and opening a
# space is only ever done with a name and a prompt one of them supplies.
#
# The validator holds this list, SKILL.md's `disable-model-invocation` and
# agents/openai.yaml's `policy.allow_implicit_invocation` to the same answer, so a skill
# cannot end up explicit-only in one runtime and automatic in the other.
address-review
land
open-pr
pr-from-review
review-queue
review-rounds
say
todo
wire-up
